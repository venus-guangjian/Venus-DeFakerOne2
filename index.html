02 — Method

三项核心设计

在约 5000 万条反伪造语料上训练一个统一模型，面临两个硬问题：训练成本与样本难度极不均衡；以及视频取证中的模态两难。下面三项设计分别回应。

/ 01

Tide-Style Tuning

像潮汐一样涨落交替的三阶段训练：LoRA 退潮（低成本对齐、保留 Qwen3.5 知识与推理能力）→ 全参涨潮（释放全部参数预算拟合大规模异质语料）→ LoRA 再退潮（低成本继续优化难样本新样本，防止在海量易样本上过拟合）

LoRA(τ₁) → merge → Full(τ₂) → LoRA(τ₃)
noise: light → medium → heavy
data: initial → full → new/hard
/ 02

Modality Synergism

在训练侧与推理侧同时使用动态模态。训练时每个视频以「原生视频」与「自适应帧率抽取的单帧图」双模态同时训练。推理时分别以两个模态进行预测，选取预测香农熵最低的模态作为选中模态。

训练: L = L_det(clip) + L_det(frames)
共享 backbone，损失独立
推理: m* = argminm Hm,  Hm = −cm log cm − (1−cm) log(1−cm)
取熵最低香农熵模态的预测作为最终判定
/ 03

Anomaly Magnifier + Calibration Loop

以 DINOMAC 为编码器强化细粒度线索感知。并用全局判定 p 动态推导像素阈值 τ(p)，让定位决策边界基于全局证据校准。同时减少: 1. 真实图上的过分割假阳和 2. 伪造图上的漏检。

τ(p) = 0.75 − p/2 = ½ + ½(½ − p)
M_cal = 𝟙[ M > τ(p) ]

② Entropy-based Test Adaptation · 模态熵路由

拖动 → 改变证据分布

哪一模态承载更强证据是样本相关且先验未知的：有些伪造证据集中在时序与跨帧上下文（闪烁、运动不一致），原生视频模态更优；有些证据集中在单帧纹理，喂视频反而用冗余时序 token 稀释注意力。推理时同时取两种模态的预测，用 Shannon 熵度量确定性，采纳更确定的一方——无需额外训练，也无需学习路由模块。

H(frame)=0.59 < H(video)=0.96 → 帧序列更确定 · 证据集中在单帧纹理（文字/logo 级编辑）

③ Calibration Loop · τ(p) 动态阈值

拖动 → 改变全局判定 p

只用区域级监督训练的像素解码器对所有输入一视同仁，容易把真实图上「显著但无害」的区域（纹理边界、强边缘、压缩痕迹）误判为篡改。校准环把定位决策边界条件化于全局判定 p：p→1 时阈值降到 0.25，弱但真实的篡改线索不再被压制；p→0 时阈值升到 0.75，只有极显著异常才能通过。p=0.5 时退化为传统固定阈值——校准从不注入全局证据不支持的偏置。

05 — New Benchmark

RRVBench · Realistic Rumor Video Benchmark

公开视频取证数据集里的假视频，多由一年以上发布的旧生成器合成。为跟上 AIGC 视频生成的演进速度，我们构建了 RRVBench：假视频全部由 7 个最新闭源与 4 个最新开源生成器合成，内容聚焦真实世界谣言场景，最大限度缩小应用鸿沟。

最新假视频生成器 ● 真实视频伪造场景

RRVBench 是视频评测中对泛化能力严苛的考验。有基线在某子集上表现尚可，却在新生成器上骤降——说明它锁定的是生成器指纹而非伪造本质。DeFakerOne2 的各子集分数相对稳定，最弱的子集仍显著高于外部方法的最佳成绩。
